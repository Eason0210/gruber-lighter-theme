#+title: Gruber Lighter
Gruber Lighter theme for Emacs.	A lighter variant of the [[http://daringfireball.net/projects/bbcolors/schemes/][Gruber Light]] theme for BBEdit by John Gruber. Adapted for deftheme and extended by Eason Huang.

** Screenshot
#+html: <img src="https://imgur.com/6c0IGnT.png">

** Installation
Download the theme to your local directory. You can do it through ~git clone~ command:

#+begin_src shell
git clone https://github.com/Eason0210/gruber-lighter-theme
#+end_src

Then add path to gruber-lighter-theme to custom-theme-load-path list —
add the following to your emacs config file somewhere (.emacs,init.el, whatever):

#+begin_src emacs-lisp
(add-to-list 'custom-theme-load-path
             "/path/to/gruber-lighter-theme/")
#+end_src

Use `M-x customize-themes` to change your current theme.
Or with use-package:

#+begin_src emacs-lisp
(use-package gruber-lighter-theme
  :load-path "/path/to/gruber-lighter-theme"
  :config (load-theme 'gruber-lighter t))
#+end_src
